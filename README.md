# Fantacalcio Asta 2026/27

PWA mobile-first personale per la gestione del listone e dell'asta.

## Requisiti

- Node.js 22 LTS o una versione compatibile con Vite
- npm
- Git
- VS Code

## Avvio locale

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## GitHub Pages

Il repository previsto è `fantacalcio-asta-26-27`.
Se usi un nome diverso, modifica `repositoryName` in `vite.config.ts`.
